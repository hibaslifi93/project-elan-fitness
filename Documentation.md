*Documentation des acquis — Élan Fitness*
*Nom : Hiba Slifi*
*Projet : Migration d’un site one page vers un site multipage*
*Présentation*
Pendant la réalisation du projet Élan Fitness, j’ai pratiqué HTML et CSS pour créer un site avec plusieurs pages. J’ai aussi appris à organiser mon travail, à chercher des informations et à utiliser des outils pour avancer lorsque je rencontrais une difficulté.
Comprendre le brief
J’ai appris à lire un brief pour identifier les pages demandées, leur contenu et les livrables à préparer.
J’ai compris qu’il faut répartir le contenu entre les pages Accueil, Programmes, À propos et Contactez-nous, puis créer des liens pour faciliter la navigation.
Organiser les fichiers et les dossiers
J’ai appris à organiser les fichiers du projet : les pages HTML, le fichier CSS et les images.
J’ai compris l’importance des noms de fichiers et des chemins. Une erreur dans un chemin peut empêcher une image de s’afficher ou un lien de fonctionner.
*Utiliser HTML*
J’ai pratiqué les balises pour ajouter des titres, des paragraphes, des images et des liens.
J’ai utilisé des éléments comme div, header, nav, main et footer pour organiser le contenu. J’ai aussi appris à vérifier la fermeture des balises et à indenter le code pour mieux le lire.
*Utiliser CSS*
J’ai appris à modifier les couleurs, les polices, les dimensions et les espacements.
J’ai mieux compris la différence entre margin et padding. J’ai utilisé des classes pour appliquer des styles et garder une présentation cohérente entre les pages.
Chercher des informations
Quand je ne comprenais pas une balise ou une propriété CSS, je consultais mes cours et des sites de documentation mes camarades et le formateur.
J’ai appris à faire une recherche précise, à lire les exemples et à les tester dans mon projet. J’ai compris qu’il faut adapter un exemple à son besoin et comprendre son fonctionnement.
Ressources consultées : [w3school     / bahja academy sur youtube].
*Utiliser GitHub*
J’ai découvert comment organiser et partager un projet dans un repository GitHub.
J’ai également découvert GitHub Pages pour publier le site et le rendre accessible avec un lien.
Vérifier et corriger mon travail
J’ai appris à vérifier le résultat dans le navigateur pendant le développement.
Lorsqu’un élément ne s’affichait pas correctement, je vérifiais le code HTML, les styles CSS et les chemins des fichiers. J’ai compris qu’avancer par petites modifications permet de repérer plus facilement les erreurs.
*Bilan personnel*
Ce projet m’a permis de progresser dans les bases du développement web. J’ai appris à mieux organiser mes fichiers, à chercher de l’aide et à corriger certaines erreurs.
Je suis encore débutante et j’ai besoin de pratiquer davantage. Ce travail m’a aidée à mieux comprendre les étapes nécessaires pour réaliser un site web.
