## Projet Elan Fitness

Bonjour, ceci est mon projet pour le brief Elan Fitness.
J'ai transformé un site one page en site multipage.
## C'est quoi le projet ?

La salle de sport Elan Fitness avait un site avec tout sur une seule page. On nous a demandé de le diviser en plusieurs pages pour que ce soit mieux pour le référencement et pour les visiteurs.

## Les pages que j'ai faites

J'ai fait 4 pages comme demandé dans le brief :
- Accueil (index.html) : présentation de la salle
- Programmes (programmes.html) : les cours et les formules
- A propos (a-propos.html) : l'histoire et l'équipe
- Contactez-nous (contactez-nous.html) : formulaire et adresse

J'ai mis le même menu dans toutes les pages pour que la navigation soit facile.

## Comment j'ai fait ?


J'ai aussi fait :
- un logo simple pour Elan Fitness
- des animations simples sur les boutons
- j'ai mis des balises title différentes et des alt pour les images pour le SEO
